# 🎬 雙語教學影片搜尋助教 v3（上位思考＋備課版）

**Teaching Video Search — an AI skill for bilingual teachers**

幫各科雙語老師找到最適合課堂的 YouTube 英語教學影片，並設計 CEFR pre-A1 課堂 Yes/No 提問。適用國小到國中，會依年級自動調整片長、字幕與提問難度。
Find the best English YouTube video for your class. Get easy Yes/No questions too. For grades 1 to 9.

作者 Author：Jimmy（臺北市天母國中 科技領域教師）

---

## 這個 skill 會做什麼？ What does it do?

1. **問清楚你要的影片** — 科目、單一概念、學生必記的一句話、必備畫面。
2. **上位思考階梯（0～3 層）** — 跳出課本術語，改用兒童英語世界的說法去找。
   例：`algorithm` → `step-by-step instructions` → `exact instructions challenge` → `how computers work for kids`
3. **真的去搜尋** — 給你 3–5 支真實的候選影片，並標明哪些條件已確認、哪些要你點開看。
4. **依你的回饋再找** — 主題偏太遠就往下退一層；太無聊就往上爬一層。
5. **備課產出** — 3–4 題 pre-A1 是非題（每題 ≤ 7 個字）＋課堂口語引導句＋繁中字幕翻譯指南。

不需要安裝任何程式，只需要 AI 有「網頁搜尋」功能。
No install. You only need an AI with web search.

## 安裝方式 How to install

### 第 1 步：下載 Download

點這個頁面上方綠色的 **Code** 按鈕 → **Download ZIP**。
Click the green **Code** button → **Download ZIP**.

### 第 2 步：上傳到你的 AI Upload to your AI

**ChatGPT**

1. 左側選單點「外掛程式 Plugins」→ 上方「技能 Skills」。
2. 點「新增 Create」→「從電腦上傳 Upload from your computer」。
3. 選剛剛下載的 ZIP 檔。

**Claude**

1. 進入「Customize」→「Skills」。
2. 上傳剛剛下載的 ZIP 檔。
3. 把這個 skill 的開關打開。

> 選單名稱可能隨改版而不同。Menu names may change.

### 第 3 步：開始用 Try it

開一個新對話，輸入：
Open a new chat and type:

> 我想找國一資訊科技「演算法」的雙語教學影片
